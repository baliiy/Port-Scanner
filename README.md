# Port Scanner in Python

My first cybersecurity project.

This project is a simple port scanner developed in Python.
It checks a range of ports on a host and identifies which ports are open.

How to run:
```bash
python scan.py HOST START_PORT END_PORT```

Example:
```bash
python scan.py localhost 1 1000```

What I learned:
- Using sockets in Python
- How a TCP connection works
- Using `connect_ex()`
- `for` loops
- Python functions
- Command-line arguments (`argv`)

Objective:
This project was created to practice Python and networking concepts
during my cybersecurity studies.
